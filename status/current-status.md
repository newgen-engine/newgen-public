# Current Status

## What this document is

This page describes the current public status of the NewGen project at a high level.

Its purpose is to clarify what exists today, what is still being finalized, and what is not being claimed yet.

## Current project structure

NewGen is being developed as three distinct but connected ecosystems:

- **NewGen L1**
- **E2 Compute Hub**
- **NewGen AI**

These ecosystems are connected, but they do not share the same role or the same authority.

## Current public status

### NewGen L1

NewGen L1 is the canonical blockchain layer of the project.

It is not presented as a generic chain.
Its role includes:

- canonical state
- finality anchoring and settlement
- governance
- adaptive economic behavior
- reputation logic
- explicit public authority over what becomes canonical

Current public maturity:
- core development substantially completed
- final low-risk refinements and validation still ongoing

### E2 Compute Hub

E2 Compute Hub is the commissioned compute and data-center layer of the project.

It is not presented as a generic orchestrator.
Its role includes:

- commissioned workload execution
- bounded off-chain job handling
- controlled participation rules
- reputation-aware node selection
- execution through the most reliable eligible nodes
- explicit separation from canonical chain authority

Current public maturity:
- core development substantially completed
- final low-risk refinements and validation still ongoing

### NewGen AI

NewGen AI is a full proprietary intelligence system being built in-house.

It is not presented as a thin assistant layer.
Its role includes:

- conversational interaction
- reasoning
- tool use
- bounded orchestration

Its internal stack already includes foundational proprietary components such as:

- tokenizer program
- run engine
- controlled data/token pipeline

A premium model with certified results is also part of the broader NewGen direction, but public material on that layer remains intentionally limited at this stage.

Current public maturity:
- core proprietary stack already built at infrastructure and pipeline level
- token generation, corpus preparation, and model-building stages still progressing
- public maturity is not yet uniform across the blockchain, compute, and AI layers

## Current phase

The project is no longer in the early construction phase.

The current phase is focused on:

- final low-risk refinements
- internal validation
- public documentation alignment
- preparation for broader public exposure

## What is not being claimed yet

This page does **not** claim:

- that public tests are currently open
- that all three ecosystems are at the same public-readiness stage
- that all internal architecture details are public
- that sensitive code or dangerous operational details will be published

## Publication posture

Public material is intentionally filtered.

NewGen will not publish source code, sensitive internal material, dangerous implementation details, or operational content that would unnecessarily increase risk.
